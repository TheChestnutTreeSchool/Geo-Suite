# Geo Suite

Feldaufnahmen für Geologie und Hydrogeologie auf dem Android-Handy oder -Tablet:

- **Wasser** – Schüttungsmessung von Quellen und Grundwasserfassungen (Stoppuhr, Sprachsteuerung, GPS, Kantonsdaten)
- **Bohrkern** – Bohrkernaufnahme mit Bohrprofil-Bericht (PDF, Word, DXF)
- **Gebäude** – Gebäudeschadstoffe (Gebäudecheck: Räume, Bauteile, Befunde, Proben, Fotos, Pläne)

## Herunterladen

Die aktuelle Version: **[Geo-Suite.apk](https://github.com/TheChestnutTreeSchool/Geo-Suite/releases/latest/download/Geo-Suite.apk)**
(alle Versionen unter [Releases](https://github.com/TheChestnutTreeSchool/Geo-Suite/releases)).

1. `Geo-Suite.apk` auf dem Handy herunterladen und antippen.
2. Die Installation aus dieser Quelle erlauben (einmalig). Mindestens Android 8.0.
3. Updates: in der App unter Einstellungen → «Nach Updates suchen». Alle Aufnahmen bleiben erhalten.

Jede Version ist mit demselben Schlüssel des Herausgebers signiert. Android installiert ein Update nur, wenn die
Signatur mit der installierten App übereinstimmt.
